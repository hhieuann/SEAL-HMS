# Test Gitflow

File này chỉ để **thử quy trình Git** của nhóm: tạo feature branch → push → Pull Request → review → merge vào `develop`.

- Nhánh: `feature/test-gitflow` (tách từ `develop`)
- Mục đích: An + bạn tập push lên GitHub và merge PR.
- Sau khi merge xong có thể xoá nhánh này và xoá file này.

## Checklist thử
- [ ] `git push` nhánh lên GitHub
- [ ] Mở Pull Request vào `develop`
- [ ] Bạn review + approve (1 approval)
- [ ] Merge PR
- [ ] Xoá nhánh đã merge
